# Example: generated code

> **Status:** planned. This example uses `facere.c`, which no release supports yet, so it does not run on the current release.

A C server whose message structs are generated from TOML specs by a Python generator, and whose keyword lookup is generated by gperf, an external tool. It tests how Facere tracks a generator's own code, a generated header that compiles need before they run, and a program the build only sometimes needs. It uses [C support](../../maintainer/design/extensions/c.md) and [Design](../../maintainer/design/README.md).

```
fac.py
messages/login.toml
messages/greeting.toml
src/keywords.gperf          gperf's keyword table
src/keywords.h              declares the lookup gperf generates
src/main.c                  includes messages/greeting.h and keywords.h
src/session.c               includes messages/login.h
tools/messages.py           the message generator, plain Python
```

## Specs and the generator

A spec such as [`messages/login.toml`](./messages/login.toml) lists a message's fields. [`tools/messages.py`](./tools/messages.py) knows nothing of Facere: it takes three paths and writes two files.

## fac.py

Each spec in [`fac.py`](./fac.py) names its outputs at collection, one header and one source, so every generated file is a declared output and compiles one by one. `message` calls the generator in its own process, so the generator's code joins each rule's fingerprint as the recipe's own code does, and `C_TYPES` by value, as every module constant the code reaches is. Its `open(spec)` is a declared input, which the audit hook confirms.

Every compile takes the generated headers as order-only inputs, so the first run generates them before any compile starts, and later runs re-execute a compile only for the headers its depfile listed. Generated sources land in `build/gen/`, which `fac.sources("src/**/*.c")` never reaches, and their objects stay beside them, since `fac.out()` keeps a path already in the output directory.

Run as a command instead, as in `fac.run("python", "tools/messages.py", spec, header, source)`, the generator would be a path among the arguments that `message` does not declare, so the rule fails, naming the `fac.Input` parameter to add, rather than missing every edit to the generator.

## Runs

| Action | Executes | Why |
|---|---|---|
| `fac` | 2 `message` rules, `keywords`, 5 compiles, the link, `compile_commands.json` | Nothing is recorded yet |
| `fac` | nothing | Every fingerprint matches |
| Edit `messages/login.toml`, then `fac` | login's `message`, 2 compiles, the link | Only login's rule inputs the spec, and of the hand-written files only `session.c`'s depfile lists `login.h` |
| Edit a comment in `tools/messages.py`, then `fac` | nothing | Fingerprints hash the syntax tree, which holds no comments |
| Change the generated text in `tools/messages.py`, then `fac` | 2 `message` rules, then the compiles whose headers or sources changed, and the link | The generator's code is part of each rule's fingerprint |
| Refactor `tools/messages.py` without changing its output, then `fac` | 2 `message` rules | Identical outputs leave every compile up to date |
| Add `messages/logout.toml`, then `fac` | logout's `message`, 1 compile, the link, `compile_commands.json` | The glob lists a new spec, and the program gains an object |
| Edit `src/keywords.gperf`, then `fac` | `keywords`, 1 compile, the link | Only the keyword table changed |
| Uninstall gperf, then `fac` | nothing | A missing program fails only a rule that must execute |
| Then edit `src/keywords.gperf` and `fac` | `keywords`, failing | `fac.run` names `gperf` as not found on `PATH` |

## Rough edges

- **Generators that choose their own output names**, such as protoc emitting a file per service, need their outputs derived at collection. Otherwise the generator outputs a directory and one rule compiles everything in it, losing per-file rebuilds for that directory, the gap ninja's `dyndep` fills.
- **Every compile waits for every generated header** on the first run, since `inputs=` orders them all before any compile.
- **`-Ibuild/gen`** joins its path to the flag without `=`, so the argument check cannot see it. Here that costs nothing, since the generated headers are already inputs.
