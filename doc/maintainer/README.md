# Maintaining Facere

The user documentation in [`../user/`](../user/) is part of the product: a change to Facere's behavior updates it in the same change. Until 1.0 it may describe behavior not yet implemented, so check the code before taking it as a statement of what Facere does today.

- [Development](./development.md) - before building, testing, or linting Facere for the first time
- [uv](./uv.md) - before adding, removing, or upgrading a dependency
- [Principles](./principles.md) - when a design question has no answer in the requirements
- [Requirements](./requirements.md) - before changing what Facere does
- [Releasing](./releasing.md) - when cutting a release
