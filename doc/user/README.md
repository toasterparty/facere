# Facere

Facere is a build tool configured in plain Python. Rules are Python functions in a `fac.py`, and Facere rebuilds exactly what changed by comparing content: of the inputs, the flags, the recipe code, and the outputs themselves. A feature marked *(0.2)* needs Facere 0.2 or newer, and one marked *(planned)* is in no release yet.

`fac --help` documents the command line.
